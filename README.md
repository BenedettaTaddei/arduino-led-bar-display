# Arduino LED Bar Display

University project for the *Architettura degli Elaboratori* course (University of Camerino).

An Arduino Nano program, written in C and simulated on Wokwi, that reads two potentiometers and shows their values as bars on two LED bar graphs. A rotary encoder scales the values up or down.

**Simulation:** https://wokwi.com/projects/467348614047726593

**Code:** `sketch.ino`
